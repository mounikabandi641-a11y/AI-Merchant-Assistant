# AI Merchant Assistant – Smart Dispute & Fraud Resolver

This repository is the initial project scaffold for a hackathon app focused on merchant fraud detection and dispute resolution.

The codebase is intentionally structured for future implementation in:
- Python + FastAPI for backend services
- React for the frontend web app
- SQLite for the initial database
- Pandas + Scikit-learn for ML preprocessing and model training

This is only the recommended folder structure. Application code will be added in later steps.
